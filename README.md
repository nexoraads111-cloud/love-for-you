**https://nexoraads111-cloud.github.io/love-for-you/**

Любой push в ветку `main` обновляет сайт автоматически.

## Хостинг Websupport (`ukstav.sk`)

Тариф **E-maily** оставляем — он нужен для:

- домена `ukstav.sk`
- почты (`@ukstav.sk`)

Отдельный **Hosting** на Websupport для этого сайта **не нужен**, пока сайт живёт на GitHub Pages.

Если позже захочешь открывать сайт по адресу `ukstav.sk`, в DNS Websupport можно привязать домен к GitHub Pages (A/CNAME). Почта при правильных MX-записях останется на Websupport.
